## 1. Degree Rotation
calculate using circumference. 
if `Circumference = 20cm` 
`1 revolution` covers 20cm distance
`2 revolution` covers 40cm distance
- convert degrees into revolutions $360\degree=1rev=20cm$ 
- if wheels made $x$ revolutions => $20cm\times x = \text{total distance covered}$

 take z = circumference
equation becomes,

$$
\boxed{z\times x = \text{total distance covered}}
$$
